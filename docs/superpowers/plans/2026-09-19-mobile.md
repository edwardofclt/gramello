# Original mobile implementation record

The original Expo mobile companion introduced shared diary screens using React
Native, TypeScript, and gluestack-ui. Its hosted account integration has been
removed. Current behavior is described in the
[mobile design](../specs/2026-09-19-mobile-design.md) and
[native local-data implementation](../../client-only-implementation.md).

## Original verification record

The original implementation passed web/mobile TypeScript checks, its focused
Vitest suite, a web production build, an isolated compiled-Worker smoke test,
and iOS/Android Hermes bundle exports. Browser checks exercised search,
exact-gram food logging, coupled goal saves, trend ranges, and entry deletion
at a 390 × 844 viewport. Screenshots were inspected as ignored test artifacts.

These historical checks do not certify the current build. Use the
[mobile verification commands](../../../mobile/README.md#verify) and
[native validation record](../../client-only-validation.md) for current setup
and device-validation requirements.
